2. Archivos de Texto vs. Binarios & Ciclo de Vida
</> 4Geeks academy

Tipos de Archivos & Ciclo de Vida

Un archivo en disco es una secuencia estructurada de bytes administrada por el sistema operativo.

Archivos de Texto: Secuencias de caracteres legibles codificados (estándar UTF-8).
Archivos Binarios: Imágenes, ejecutables o buffers que no son texto plano directamente.
🔄 Ciclo de Vida Obligatorio:

Abrir (Open) ➔ Operar (Read/Write) ➔ Cerrar (Close).
Dejar archivos abiertos genera dangling handles y bloquea recursos del SO.

Modos de Apertura en Disco

Escribir ('w' vs 'x'):

'w' sobreescribe todo el archivo. 'x' es exclusivo y lanza FileExistsError si ya existe.

Leer ('r'):

Accede a un archivo existente. Lanza FileNotFoundError si no existe la ruta.

Anexar ('a'):

Agrega contenido al final del archivo sin alterar los bytes previos.

Borrado Seguro (Path.unlink):

Elimina archivos comprobando su existencia previamente.

3. Operaciones Básicas en Disco

Código Seguro en Python

Ejemplo práctico de escritura con sobrescritura, anexado al final y borrado seguro con pathlib.Path.

💡 Codificación UTF-8

Especificar siempre encoding='utf-8' al abrir archivos evita errores de caracteres entre Windows, Mac y Linux.

file_operations.py
Python
from pathlib import Path

# 1. Crear y escribir ('w' sobreescribe todo)
with open('registro.txt', 'w', encoding='utf-8') as f:
    f.write('Línea 1\n')

# 2. Anexar sin sobreescribir ('a')
with open('registro.txt', 'a', encoding='utf-8') as f:
    f.write('Línea 2\n')

# 3. Eliminar de forma segura con pathlib
archivo = Path('registro.txt')
if archivo.exists():
    archivo.unlink()
4. Manejo Defensivo & Writing Pitfalls
</> 4Geeks academy

3 Reglas de Oro para Evitar Errores Comunes

Prácticas de ingeniería para escribir código robusto que previene corrupción de archivos y fugas de memoria:

🔒
1. Context Manager (with)

El uso obligatorio de with open(...) as f: garantiza que el archivo se cierre automáticamente al salir del bloque, incluso ante excepciones imprevistas.

↵
2. Saltos de Línea (\n)

El método .write() no inserta saltos de línea automáticamente. Omitir \n concatena registros y corrompe archivos estructurados.

⚡
3. Streaming O(1)

Evitar .read() o .readlines() en archivos grandes. Iterar directo (for linea in f:) procesa línea a línea con memoria constante O(1).

5. Manipulación de CSVs con DictReader / DictWriter
</> 4Geeks academy

Módulo Nativo csv

Permite interactuar con datos tabulares mapeando automáticamente las columnas a diccionarios de Python.

DictReader: Lee la cabecera como llaves y cada fila como diccionario.
DictWriter: Escribe listas de diccionarios a disco con writeheader().
csv_handler.py
Python
import csv

# Lectura: de CSV a lista de diccionarios
def leer_csv_a_dicts(ruta: str) -> list[dict]:
    with open(ruta, 'r', encoding='utf-8') as f:
        lector = csv.DictReader(f)
        return [dict(fila) for fila in lector]

# Escritura: de lista de diccionarios a CSV
def guardar_dicts_a_csv(ruta: str, datos: list[dict], cabeceras: list[str]):
    with open(ruta, 'w', encoding='utf-8', newline='') as f:
        escritor = csv.DictWriter(f, fieldnames=cabeceras)
        escritor.writeheader()
        escritor.writerows(datos)

def calcular_metricas(filas: list[dict]) -> dict:
    total = sum(float(f['monto']) for f in filas if 'monto' in f)
    return {

    }

8. Prerrequisito 3: Streams en Memoria (io.StringIO)
</> 4Geeks academy

🧠 ¿Por qué se necesitan?

csv.DictReader requiere un objeto de tipo archivo (file-like object) que pueda ser leído línea por línea.

🚀 Cero I/O de Disco en la API

Al recibir bytes por HTTP, io.StringIO convierte el texto en un archivo virtual en memoria RAM, evitando guardar archivos temporales en disco.

memory_stream.py
Python
import csv
import io

# Texto en memoria (ej. recibido en la API HTTP)
contenido_bytes = b"id,producto,precio\n1,Laptop,1200\n2,Mouse,25"
texto = contenido_bytes.decode('utf-8')

# io.StringIO simula un archivo abierto en disco
stream_memoria = io.StringIO(texto)
lector = csv.DictReader(stream_memoria)

filas = list(lector)
# [{'id': '1', 'producto': 'Laptop', ...}, ...]
9. Prerrequisito 4: Endpoints HTTP (UploadFile)
</> 4Geeks academy

🌐 ¿Por qué se necesitan?

Permite a clientes (Frontend Web, Mobile o Postman) enviar archivos usando el estándar multipart/form-data.

🛡️ Validación HTTP Defensiva

Valida el tipo de archivo y responde con códigos HTTP correctos (400 Bad Request o 200 OK).

upload_endpoint.py
Python
from fastapi import APIRouter, UploadFile, File, HTTPException

router = APIRouter()

@router.post("/api/upload")
async def subir_csv(file: UploadFile = File(...)):
    if not file.filename.endswith('.csv'):
        raise HTTPException(status_code=400, detail="Formato no permitido. Usar .csv")

    contenido_bytes = await file.read()
    return {"filename": file.filename, "size_bytes": len(contenido_bytes)}
10. Paso 1: Módulo Central con Lógica Pura
</> 4Geeks academy

Lógica Reutilizable

La función analizar_ordenes procesa filas en memoria, valida estados y calcula métricas sin saber de dónde provienen los datos.

⚙️ Desacoplamiento Total

Este módulo puede ser llamado por un script CLI, un endpoint de FastAPI o una tarea programada.

core/orders_analyzer.py
Python
def analizar_ordenes(filas: list[dict], estados_validos: set) -> dict:
    validas, invalidas = [], []
    total_ventas = 0.0

    for fila in filas:
        orden_id = fila.get('order_id')
        estado = fila.get('status')
        monto = fila.get('amount')

        if not orden_id or not estado or estado not in estados_validos:
            invalidas.append({'fila': fila, 'motivo': 'Datos incompletos o estado inválido'})
            continue

        try:
            monto_num = float(monto)
            validas.append(fila)
            total_ventas += monto_num
        except (ValueError, TypeError):
            invalidas.append({'fila': fila, 'motivo': 'Monto numérico no válido'})

    return {
        "total_procesadas": len(filas),
        "total_validas": len(validas),
        "total_invalidas": len(invalidas),
        "total_ventas": round(total_ventas, 2),
        "invalidas_detalle": invalidas
    }

import sys
import csv
from core.orders_analyzer import analizar_ordenes

def main():
    if len(sys.argv) < 2:
        print("Uso: python analyze_orders.py <ruta_archivo.csv>")
        sys.exit(1)

    ruta = sys.argv[1]
    with open(ruta, 'r', encoding='utf-8') as f:
        lector = csv.DictReader(f)
        filas = list(lector)

    resultado = analizar_ordenes(filas, {'completada', 'pendiente', 'cancelada'})
    print(f"Válidas: {resultado['total_validas']} | Inválidas: {resultado['total_invalidas']}")
    print(f"Total Ventas: ${resultado['total_ventas']}")

if __name__ == '__main__':
    main()
12. Paso 3: Punto de Entrada Backend API (FastAPI)
</> 4Geeks academy

Servicio HTTP en FastAPI

El endpoint recibe el archivo por HTTP (UploadFile), lo decodifica y usa io.StringIO para leer el CSV en memoria sin tocar el disco.

✨ Cero Duplicación de Código

Tanto el CLI como la API reutilizan exactamente la misma función analizar_ordenes.

services/api/routes.py
Python
from fastapi import APIRouter, UploadFile, File, HTTPException
import csv, io
from core.orders_analyzer import analizar_ordenes

router = APIRouter()

@router.post("/api/orders/analyze")
async def endpoint_analizar_ordenes(file: UploadFile = File(...)):
    if not file.filename.endswith('.csv'):
        raise HTTPException(status_code=400, detail="El archivo debe ser un CSV.")

    contenido = await file.read()
    texto = contenido.decode('utf-8')
    lector = csv.DictReader(io.StringIO(texto))
    filas = list(lector)

    # Reutiliza la misma función central
    return analizar_ordenes(filas, {'completada', 'pendiente', 'cancelada'})
