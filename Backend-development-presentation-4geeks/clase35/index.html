💡 Analogía Práctica:

🎯 El Objetivo (Goal)

Es el propósito o meta final asignada al agente. Define con claridad qué resultado debe lograr y las condiciones para dar por terminada la tarea.

🧠 El Modelo (LLM)

Es el motor de razonamiento (como GPT o Gemini) que procesa las observaciones, toma decisiones y determina qué herramientas ejecutar en cada paso.

flowchart TD
    Start[Inicio] --> InitMemory[Inicializar memoria con la entrada del usuario]
    InitMemory --> LoopStart{¿Iteración menor que max_iterations?}
    LoopStart -- No --> End[Devolver mensaje de respaldo: Se alcanzó el máximo de iteraciones]
    LoopStart -- Sí --> CallLLM[Llamar al LLM con el prompt del sistema y la memoria]

    Decision -- llamada a herramienta --> ExecuteTool[Ejecutar herramienta con los argumentos dados]
    ExecuteTool --> AppendMemory[Agregar resultado de la herramienta a la memoria]
    AppendMemory --> LoopStart

# Función para construir el prompt del sistema

def build_system_prompt(tools: dict, objective: str) -> str:
    # Comienza con el objetivo del agente
    prompt = f"Eres un agente. Objetivo: {objective}\n"
    prompt += "Herramientas disponibles:\n"

    # Añade el nombre y descripción de cada herramienta
    for name, info in tools.items():
        prompt += f"- {name}: {info['description']}\n"

    # Indica al LLM el formato exacto de respuesta JSON
    prompt += (
        "Responde con JSON en uno de estos formatos:\n"
        '{"type": "tool_call", "tool": "tool_name", "args": {}}\n'
        'o {"type": "final_answer", "content": "..."}\n'
    )

    return prompt
